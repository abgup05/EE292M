# The fourth referee, finding by finding (version 11.1)

The referee read version 11 with read-only tools and could run nothing ([its text, unedited](reviews/referee-4-version-11.md)). Every claim it made about the code was checked against the code before anything was changed, and every fix began as a test that failed. Seven of the eight findings were true as written or truer; one was already fixed in the commit after the tag it read. Version 11.1 is the answer.

The gate at this version, from a fresh clone: 1,580 offline tests, the smoke test and 156 assertions on the rendered page (`make verify-fresh`, [`evidence/verify-fresh.txt`](evidence/verify-fresh.txt)).

## What the referee could not confirm, answered

- **"1,499 tests; I counted 970 test functions."** Both are right: many tests are parametrised, and pytest counts each case. It collects 1,580 at this version.
- **"`verify-fresh.txt` is from another commit, not HEAD."** It is taken again at the commit this version is tagged at, and says which.
- The evaluation counts, the published values, the comparison's counts and the period tables are outputs of commands the referee could not run. Each is in the repository beside the command that makes it; none was re-derived by a person.

## What this reading showed

Two numbers this project had published were wrong, and both were measurements described with care: twenty alternating pairs, a spread, a repeat. The benchmark's own pairs held the evidence against its summary, and nobody had read the pairs. The live timing measured a request the app does not make. And the one sentence in the speed note that was a guess ("mostly rebuilding the documents") was the one that turned out false when it was finally timed: 1 ms.

The stricter quote rule changed nothing on the recorded answers. That is good news about those answers and no evidence about the rule: it has only ever been shown cut quotes that a test wrote.

## Still open after this version

- An older quarterly report a run read is compared with nothing.
- About 45 ms of every run is not attributed to any stage.
- One wrong year beside right ones is missed in 5 of 18 planted cases, and the wrong column of a table still passes.
- A bare number still matches an amount at table scales.
- A bare web address in an exported excerpt can still be made clickable by a viewer.
- Every model answer is still a recording made by a stand-in. The referee is another Claude model, not an independent party.
