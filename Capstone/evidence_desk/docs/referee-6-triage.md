## What this reading showed

The findings that matter are 1, 2 and 3, and all three are in checks that had been read by referees before. The quote gate was the first thing this project built and the claim it carries, that a number cannot be lifted out of its context, was tested for a cut inside the digits and never for a cut beside them. The meaning check was added in version 5 and measured for how often it rejects; what a "partly" does to a verdict was never asked, because nothing printed how common "partly" is until a live run's sample was committed. And the period check's doc describes the fiscal case the code returns early from.

Version 14.2's own work was not read. The next referee needs a brief that names it.
