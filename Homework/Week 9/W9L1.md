## 3. The blind review of version 7

Twelve findings against the Week 6A checklist. The five about the page were right about the page as tagged; the seven about the tests were each checked against the test they name.

**The message.** The first screen described the tool and gave a caveat, and never said the one thing a reader should take away: that every verdict opens to the passage or figure behind it (F1). The sample link was small print under an empty form.

**The interface.** "Rejected" named two marks, a refused input and a finding I rejected (F2). The legend said a dashed border "always" means one thing where the page uses it for three (F3). Nothing on the page marked the parts that no person has checked (F4). The glyph for a complete run was a dark square, like the one for an accepted finding (F5).

**The tests.** The reviewer's wrong program is the one this project cannot yet rule out by a test: quote any real sentence, call it support, and every mechanical check passes (F6). The tripwire did not cover the comparison of two filings (F7). The smoke test compared the version with a literal (F8). What `testing.md` called "end to end" runs on recorded filings through a fake (F9). No test put one quote in two offered passages (F10). A page test could pass against a stale dump (F11). No runtime of the gate was written down (F12).

| Finding | Decision |
| --- | --- |
| F1: the first screen does not state the takeaway | Accept. One sentence at the top says it; the sample links sit beside it; the note about recorded answers is one line with the rest behind a disclosure |
| F2: "Rejected" names two marks | Accept. A refused input is "Refused" |
| F3: a dashed border "always" | Accept. The legend says "not final" and names the three cases |
| F4: no mark on what no person has checked | Accept. One mark, defined once, on the comparison's classification and on the new list of changes under each claim |
| F5: complete and accepted look alike | Accept. The complete status has a glyph of its own; a dark tag is the reader's decision and nothing else |
| F6: a real but irrelevant quote passes every mechanical check | Accept, as a measurement. A planted-mismatch evaluation puts real quotes under statements they do not belong to and counts how many the second model rejects. Of 152 planted mismatches it rejected 149, called 3 "partly" and agreed with none; with their own quotes it had rejected 1 of the same 76 findings. The answers are a stand-in's, and a swapped quote is the easy kind (`Capstone/evidence_desk/eval/README.md`) |
| F7: the tripwire does not cover the comparison, and cannot tell a wrong change from a meant one | Accept the first: a `changes` stage. The second needs a rule enforced at merge, and there is no CI here: answered in `Capstone/README.md` |
| F8: a literal version in the smoke test; the smoke test starts no run | Accept the first. Not the second: the smoke test is network-free on purpose, `make test` runs the whole pipeline in the same image on recorded filings, and `make live-walk` runs it live: README |
| F9: "end to end" is a regression check on fakes | Accept the wording. `testing.md` says so and names `make live-walk` as the only live one |
| F10: a quote in two offered passages | Accept. Test added. The gate already located it in the passage the finding names; breaking that fails the test |
| F11: a timing test may flake; a stale dump may be read | Accept the second: a page test now fails if its dump is older than the page. The timing test already compares a ratio and takes the best of five runs |
| F12: no measured runtime | Accept. `docs/testing.md` records it: the offline tests take 21 s and the whole gate from a fresh clone 33 s, with the image already built |

## 4. One suggestion, and what I decided

**The suggestion** (F6): add a test with a planted, real but irrelevant quote and assert that it does not count toward a verdict.

**Decision:** built as an evaluation, not as a test. A test would replay one recorded answer and prove only that the recording is replayed. The evaluation asks the second model about every such planted case and reports the rate, with the cases it missed listed. It is the first evidence either way about the one check in this project that is a model's opinion.
