# Evidence Desk versions, sessions and reviews

One row per tagged version of the capstone. What each version added is from the milestone table in the [capstone plan](../Capstone/README.md). The session, hand-in and work log are from the session table in the [root README](../README.md) and the hand-ins themselves. The reviews are the files in [`Capstone/evidence_desk/docs/reviews/`](../Capstone/evidence_desk/docs/reviews/README.md).

No hand-in asks a colleague for a review. The review hand-ins (W5L1, W6L1, W7L1, W8L1 and W9L1) each say there was no review session with colleagues and that the version was reviewed instead by a model that did not write it (Claude Sonnet 5.5), read-only and in a fresh context; W8L2 and W9L2 say the same model was the referee. The last column says what that hand-in states the reviewer was given or asked to look at. A blind review works from the session's checklist. A referee is the agent in `.claude/agents/referee.md`, told to expect the work to be wrong and to attack the project's claims about itself.

Each snapshot is a recorded, read-only copy of that version's page, exported from the version running locally (`make site-export`). It shows the version's own sample records and starts nothing. Versions 12 and later were built after Week 9B, the last session with a hand-in, so they belong to no session.

To open a version locally, run `make versions-up VERSIONS="N"` from the repository root. It starts version N from its own checkout of its tag at `http://127.0.0.1:87NN` (version 3 at <http://127.0.0.1:8703>, version 13 at <http://127.0.0.1:8713>); without `VERSIONS` it starts 1 to 11, and `make versions-status` shows which are up.
Version 11.1 has no port under that rule: run `git checkout capstone-v11.1`, then `make up`, and open <http://127.0.0.1:8766>.
